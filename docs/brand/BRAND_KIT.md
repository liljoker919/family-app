## Logo Concept — "The Hey Hub"

### Symbol
- A rounded house shape made from connected dots/lines
- One dot slightly offset → represents each family member
- Subtle "chat bubble" influence → ties into "Hey"

### Hidden Meaning
- Connection + communication + shared life
- Organized, but still human

### Style
- Soft corners, slightly chunky lines (friendly, app-first)
- Not perfectly symmetrical (adds playfulness)

### Color Use
- Blue base
- Accent dots in Mint + Coral

---

## App Icon

## UX Branding Details

What will make this feel premium:

- Use rounded UI elements (buttons, cards)
- Subtle animations — things "snap into place"
- Occasional humor, but don't overload it
- Keep layouts clean → humor should be the flavor, not the structure

---

## Brand Do's & Don'ts

### Do
- Keep things simple and fast
- Use humor sparingly but consistently
- Design for tired parents, not power users

### Don't
- Overcomplicate features visually
- Go full "kids app" with colors
- Sound like corporate productivity software
